# 导演决策与镜头设计

动手摆相机前，先定清楚观众这一镜要看懂什么、从谁的视点看、怎么跟其他镜头比较。本页给出从观看任务到机位变量的决策表、单镜设计卡、参考职责卡以及常见复合运镜的设计转译方法。

## 一、先定观看收益，再定控制量

按「观看任务与视点 → 必须读清的事件 → 空间与遮挡 → 构图与清晰区 → 运动与节奏 → 验收方式」六步倒推机位。下表列出七类常见观看任务对应的可选方案与取舍代价：

| 观看任务 | 可比较的方案 | 选型判别与代价 |
|---|---|---|
| 读细节 | 移机接近、原位变焦、切近景、焦点转交 | 需要新的空间透视关系选移机接近；只想放大取景选变焦或切近；只想转移清晰重点选拉焦（投影大小不变）。 |
| 揭示环境 | 后拉、横移、升高、摇向画外 | 先交代起初被什么遮挡，终点新增哪些空间信息，判断新增信息是否值得占用这段时长。 |
| 伴随人物 | 前导、尾随、平行侧跟、斜向超越 | 看表情选前导或侧前，看目的地选尾随，看身体动作选平行侧跟；提前核对人机距离与通道宽度。 |
| 读反应与双人关系 | 固定双人、延迟缓推、有限横移 | 算清听者何时反应、前景肩部是否挡住手脸，以及是否需要两人同时落在清晰区内。 |
| 读结构与材质 | 有限弧移、斜向推拉、侧移 | 确认转出的新侧面建模完整，高光随视角移动符合固定世界光源。 |
| 留白与悬念 | 固定、慢移、部分遮挡 | 保留悬念的同时，确保观众依然能读懂推进剧情的关键线索。 |
| 节奏与形式 | 滚转、规律摇移、快速变焦 | 形式感本身可以成立，无需硬塞剧情；仍要设计清晰可读的落幅。 |

### 分清视点身份与时间窗

1. **明确视点身份**：区分客观旁观、情绪贴近、严格角色双眼视点、剧情内手机持机视点。情绪贴近可以靠机位靠近和焦段收束完成，无需把相机硬塞进角色眼睛位置；剧情内手机视点要遵守真实物理边界，保持合理的转向滞后与通道限制。
2. **按时间窗分配复杂度**：一个主摄影行为可以同时包含后拉、升高、俯仰与跟焦。手部接触、微表情和换侧抢占同一个短时间窗时，优先保住已锁定的核心表演事件，错峰调整观察顺序、清晰区或运动路径。用户明确指定强运镜时保留其核心运动，通过路径与构图解决遮挡。

## 二、单镜设计卡

做方案与交接时，按本镜需要填清关键字段，未知坐标先标「待实测」，从已读场景里取真值。凡是写到「向左 / 向右」，一律注明是世界方向、相机局部、人物自身还是画面方向。秒数按场景实际 `fps / fps_base` 换算，保留真实帧与子帧。

```text
镜号 / 观看任务：
锁定项 / 可调整项：角色身份、当前状态、表演动作、场景地标、声音节拍、时长、摄影方式
源工程信息：工作副本路径与 SHA；场景名；实际 fps/fps_base；单位；画幅与像素比
视点身份：客观 / 情绪贴近 / 主观 / 剧情内持机 / 明确虚拟
入口状态：有效起帧；机位、高度与朝向；景别；人物与地标位置；已有动势
主摄影行为：位置轨迹 / 朝向 / 焦距或视场 / 焦点，写明各自变化与保持项
触发与时间窗：刺激帧、反应帧、揭示帧、可读窗口与落幅帧
相对运动：主体路径、相机路径、参考坐标系、距离与画面尺度变化趋势
空间证据：前中远景层、遮挡解除时机、可见侧面与地标参照
构图检查帧：起幅、核心事件帧、最大动作伸展帧、遮挡峰值帧、转向帧、落幅
清晰与照明：清晰对象与景深范围、对焦距离、固定世界光源与镜面反射风险
有效出口：落幅实际状态、未完成动作、世界方向与速度趋势
接镜职责：动作延续 / 注意力转交 / 空间揭示 / 节奏反差
执行映射：走 camera shot-table / camera copy / 原生曲线准备 / 现场预演
验收记录：检查帧段、通过条件、预览证据与待验项
```

## 三、参考职责卡

混用多份参考图或参考片时，给每份参考划清管辖范围，防止元素串味：

- **人物参考**：只管角色身份、比例与服装。
- **状态参考**：只管当前姿态、持物与伤口/道具状态。
- **场景参考**：只管空间布局、通道与地标位置。
- **动作参考**：只管演员身体运动轨迹与节奏。
- **摄影参考**：只管选定的运镜路径、速度趋势、起落景别与构图比例，不把参考片里的演员、背景和配音带进当前工程。

多份参考冲突时，按「当前工程已锁定项 → 表演与空间真实性 → 摄影参考表现」的顺序裁决，并记录放弃了哪一项。

## 四、方案比较与变更记录

做 A/B 候选对比时，保持同一源工程、同一帧段、同一画幅与同一显示模式。每次变更只动少量相关变量，逐项写出观看收益与代价，用具体画面依据代替笼统的「更有电影感」。

- **单独验证焦距或机位**：想看焦距本身的取景变化就锁死机位；想看透视关系变化就固定焦距移动机位。
- **联合变化要双标**：为了保持主体大小不变而同时拉远机位并增大焦距时，同时记录位置与焦距两项改动。

### 典型设计转译一：双人延迟缓推

适用于对话中听者先给出反应、相机再缓慢贴近强化关注的双人镜头：

1. **保护既有调度**：保持双方站位、桌侧轴线、手部动作与场景主灯不变。
2. **先读反应再定起点**：查出听者开始反应和达到峰值的真实帧，预留足够的反应读取时间，再沿允许的桌侧路径沿光轴缓推。
3. **拆开路径准备与缓动事务**：如果原相机是静态机位，先在工作副本上用原生关键帧建好起止位置曲线（区间外保持常量外推，确保推进前稳住入口画面），再走 `camera copy` 的运镜缓动事务把推进段调成平顺缓入缓出。
4. **权衡速度与时长**：切点固定时，启动越晚，推进段越短、峰值速度越高；如果想保持原有推进速度，先评估是否允许推后落幅与切点，并复查下一镜衔接。
5. **做同源 A/B 预演**：需要对比「即时推进」与「延迟推进」时，在同一份工作副本上准备两台各自独占 Camera Data 与 Action 的相机，各自完成缓动事务后冻结共同源，通过镜头表候选在 `camera session-live` 里同帧对比与全段播放。

### 典型设计转译二：推拉变焦（后拉增焦 / 推近减焦）

适用于主体在画面里近似等大、背景相对比例急剧放大或缩小的特殊表达：

1. **三项协同规划**：同时规划相机位移轨迹、焦距随时间变化曲线以及焦点持续跟随轨迹。
2. **用投影算式校验方向**：按 `h = f × H / Z` 核算起止帧的距离与焦距配比，确保主体高度基本稳定，背景按预期方向缩放。
3. **连续画面复核**：用连续预览检查全程透视过渡、背景比例变化和焦点清晰度，避免只看首尾两张静帧就拍板。

## 五、七组可复用判别练习

遇到团队对某种运镜效果拿不准时，挑对应的小练习在测试工程里跑一遍，用同条件对照建立直觉：

1. **推近对比变焦**：起止两帧让主体大小完全一致，对比前后景比例与遮挡关系的变化。
2. **横摇对比横移**：同一主体配至少两个不同深度的背景地标，观察层间视差差异。
3. **恒距跟随对比渐近跟随**：沿同一人物路线，比较固定距离与缓慢拉近的压迫感差异。
4. **启动早晚对比**：同一刺激与反应帧，只改相机启动延迟，对比情绪落点与峰值速度。
5. **同侧覆盖对比可见越轴**：对比保持轴线与连续运动越轴后的方向清晰度与关键接触可读性。
6. **二维同速层对比分层差速**：对比前景、中景、远景按不同速度平移时的深度线索与脚底贴地感。
7. **归零切镜对比带余势切镜**：对比每镜停稳再切与保留运动余势直接切镜的连贯节奏。
