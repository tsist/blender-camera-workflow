# 题材、媒介与支撑特征

不同题材的观众关注点完全不同，二维分层与三维场景的相机机制也有差别。本页整理九类常见题材的优先保护项、二维与三维摄影转译做法、八类实拍支撑设备的虚拟运动特征，以及全路径排练与光区反射核对要点。

## 一、按题材确定优先保护项

| 题材 | 优先保护的观看任务 | 常见取舍与排查重点 |
|---|---|---|
| 双人文戏 | 人物关系、视点归属、说者与听者反应 | 固定双人保留反应时间差，延迟缓推强化情绪；按剧情需要选择双人同清或拉焦，无需每句台词都切换焦点。 |
| 动作与追逐 | 发起 → 接触或避让 → 反馈 → 恢复的完整链路 | 优先保住关键接触帧和支撑脚可读；换侧常放在回合间隙，强同步动作也可成立；长镜头与快切按节奏各取所长。 |
| 舞蹈、健身与体育 | 肢体动作证明或相机参与共舞 | 核对头、手、脚和衣摆的动作峰值与落地支撑；大角度环绕会改变动作投影方向；球类或道具离手后提前定好跟人还是跟物。 |
| 多机演出 | 舞台空间关系、个人分句、乐器演奏与观众反馈 | 按实际曲目段落分工各机位，始终保留至少一台稳妥覆盖机位，避免所有机位同时找构图。 |
| 手机与朋友纪实 | 持机者与现场事件的参与关系 | 听见动静后转向、让路和轻微滞后要带真实因果与恢复；关键结果保持可读，用合理身体动态替代持续高频猛晃。 |
| 人物与服装展示 | 轮廓剪影、版型结构、动态垂感与面料质感 | 全身证明镜头保留头顶、脚底和抬手余量；遮挡换装切镜对齐行进方向与动作相位；区分人物自转与机位绕行。 |
| 产品、食物与微距 | 立体结构、材质质感与标识可读性 | 区分产品转台旋转（背景不动）与相机绕行（背景转动）；世界光源固定，全程核对高光走向；微距下极小位移也会改变焦点和遮挡。 |
| 建筑、风景与漫游 | 空间地标、尺度感、通道连通与平面布局 | 扫视全貌用横摇，解除遮挡用横移，交代布局用升高，进入空间用推进；密集竖线立面在目标帧率下重点查跳格顿挫。 |
| 沉浸式与立体媒介 | 特定头戴或全景观看关系 | 借鉴舞台平面图、预演和可进入区域规划，舒适距离和运动速度按当前普通二维画幅重新标定。 |

全身展示按段落安排，无需每镜都给全身；情绪特写同样结合环境镜头错峰安排。动作重音与运镜重音可以同步爆发，也可以错峰铺垫，以观众读清核心信息为准。

## 二、二维、2.5D 与三维摄影转译

跨二维动画与三维 Blender 协同工作时，把软件术语翻译成明确的空间动作：

1. **翻译二维摄影简称**：二维动画里的 `PAN`、`Follow`、`TU`、`TB` 在不同软件里可能指图层平移、取景框缩放或真实相机移动。交接镜头表时同时写清三件事：演出意图、具体哪几层或哪台相机在动、画面上的可见结果。
2. **用多平面制造差速深度**：把远景、中景、前景放在不同深度层上，横移或推拉时会产生自然的视差层次。层平移适合呈现深度错位，需要露出角色背面或大角度转体时，提前准备转面原画、结构参考或三维辅助模型。
3. **保护有限帧角色表演**：二维或三渲二角色常采用一拍二、一拍三、持帧或快过渡，完全可以和平滑的相机曲线共存。分别保护角色动画曲线与相机曲线，保持角色原有节拍，同时检查支撑脚与地面相对运动，防止背景滑移造成脚底漂滑。
4. **三维路径的物理与虚拟边界**：三维相机全程核对穿墙、近裁切、前景遮挡和视点身份。写实手机或现场跟拍遵守真实墙体与通道约束；若本镜采用明确的超现实穿墙或微观穿行路径，在设计卡里写清其内部连续逻辑。

## 三、八类支撑系统的虚拟运动特征

先定清楚镜头需要什么样的路径和控制，再参考对应实拍支撑设备的运动特性做曲线设计：

| 支撑参考 | 实拍结构特点 | 虚拟相机可转译的运动特征 |
|---|---|---|
| 三脚架与液压云台 | 配平与阻尼独立，横摇与俯仰阻力可分开调 | 固定观察点、克制的启动与制动阻尼、干脆的落幅停稳 |
| 滑轨与轨道车 | 受地面、直轨弯轨与焦点标记约束 | 均匀平滑的水平位移、明确的距离变化与同步跟焦 |
| 手持与肩扛 | 受握持重心、步态起伏、疲劳与反应影响 | 带因果的轻微角度与位置残余、转向后自然恢复稳定 |
| 机械稳定器（Steadicam） | 万向节、配重与弹簧支臂协同承托 | 连续长距离顺滑穿行，保留轻微柔和的身体呼吸感 |
| 电动三轴稳定器（Gimbal） | 强项在角运动稳定，垂直步频起伏需另控 | 地平线和光轴高度稳定，行进时Z轴微幅起伏与朝向分离 |
| 摇臂与伸缩臂 | 底座、臂长、伸缩与遥控云台分层控制 | 高度轨迹与俯仰指向分开设计；固定臂长末端呈弧线运动 |
| 索道、航拍与车载 | 平台大范围高速移动，云台独立锁目标 | 平台大路径与云台观察目标分层控制，留清障碍物安全边距 |
| 运动控制（Motion control） | 计算机精确重放多轴轨迹与光学参数 | 路径、焦距、焦点、灯光与触发精确同步，便于多遍合成 |

在 Blender 里模拟设备惯性、阻尼滞后或手持残余运动时，把这些曲线放在独立修改层或父级空物体上，方便随时关闭、减半或手调，保持主轨迹干净。

## 四、全路径排练与全程环境核对

1. **先走表演，再走相机，再合灯与切点**：先核清演员动作的真实时间与接触点，再铺相机路线，最后合并灯光、反射、支撑与切点；发现冲突时迭代微调，保持全程同步。
2. **排查空间与反射穿帮**：检查门框宽度、墙体厚度、近裁切距离、终点光区、玻璃和金属表面的反射穿帮。相机移动时画面亮暗占比和反射角都会随之变化，世界主灯固定后高光在物体表面自然流动。
3. **按任务处理光区与曝光**：人物留在稳定光区、背景明暗变化时保持曝光稳定；人物穿越明暗交界时，按风格选择补光衔接、平滑过渡曝光或保留真实明暗反差。
4. **守住参与式持机的支撑逻辑**：第一人称或手机跟拍时，单手拿道具由另一手稳住镜头；需要双手同时离开镜头时，先交代放置支撑物或交接给他人。现场收声随距离和朝向变化，剧情片独立混音按叙事视点安排，两套逻辑分开记录。
5. **留出合理的剪辑余量**：在目标取景框外起速和减速可以截出匀速段，也可以保留「发现目标」的启动瞬间。按剪辑需求留头尾余量，避免每镜生硬塞进几秒空等。

## 五、经典案例的方法迁移

参考成熟影视案例时，只抽取它们解决具体拍摄难题的方法，按当前场景条件灵活落地：

- **投影协同（如推拉变焦案例）**：用距离与焦距反向协同制造空间压迫，重点在全程投影与焦点同步。
- **时间与场景联合排练（如一镜到底战争片案例）**：先测透演员走位耗时，再反推场景通道尺寸与机位交接点。
- **内部段落与隐藏接缝（如连续长镜头案例）**：把长镜头拆成清晰的观看段落，设计自然遮挡或暗部完成隐蔽交接。
- **摄像与表演共舞（如歌舞片案例）**：把相机节奏写进走位排练，让运镜重音和肢体动作彼此呼应。
- **动作可读与狭小空间反射处理（如高强度动作片与狭小场地 MV 案例）**：提前标出镜面反射角和灯具避让路线，保证高速度运动下主体轮廓与接触清晰。
- **多机分工与固定机位观察（如多机演出与克制固定镜头案例）**：明确各机位职责边界，善用扎实稳定的固定构图让画内信息自己发声。
