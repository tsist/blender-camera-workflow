# 连续性、可读性与审看排查

相机运动和切点好不好用，最终看连续播放时观众是否能顺畅读懂空间、方向、动作和焦点。本页给出空间轴线核对、六类接镜标准、速度与快门算式、可见表面采样排查、三遍审看流程以及 13 类常见症状首轮排查表。

## 一、空间地图与 180 度轴线

动笔调切点或换机位前，先画一张最小场景平面图，标清人物、关键地标、行进路线、相机可通行区和主要观察方向。尚未核实的位置标「待实测」，从场景里读取真实坐标。

1. **分开记录三种方向**：世界方向、人物自身左右、画面左右各记各的。相机越过轴线换到另一侧后，同一条世界行进路线在画面里会反向；横移同时配合跟摇时，近景与远景的画面移动方向也可能相反。
2. **活用 180 度轴线**：同侧布机让左右关系和眼线自然可读。需要换侧时，采用连续运动越轴、轴上过渡镜、人物重新走位或插入重建全景四种做法重新建立新方向。多人互动按当前对话双方实时更新局部轴线；越轴途中检查轮廓重叠，保持关键手部接触清晰可见。
3. **区分三种看不清的原因**：物理遮挡、虚焦脱焦、背景同色低对比属于三种独立问题，对症下药，分别通过改机位、调景深或调灯光材质解决。

## 二、接镜核对与有效出口

分清三类连续：单镜内部连续、同工程切镜连续、跨工程续接。调整镜头表切点只改变画面切换时机；需要同步改变演员动作时间或整片时长时，另行协同动画和剪辑部门。

| 接镜方式 | 重点核对项 |
|---|---|
| 动作中切与动作匹配 | 核对动作起因、当前相位、接触点、支撑脚或持物手以及剩余动势，让两镜在动作进程上顺畅衔接。 |
| 方向与眼线 | 核对世界行进路线、当前轴线、视线落点与目标位置，保证观众一眼看清谁在看谁。 |
| 图形匹配 | 核对轮廓、位置或运动图案的呼应关系，同时按叙事需要交代时空是否切换。 |
| 遮挡切与甩镜切 | 核对进出方向、画面尺度、明暗亮度、速度趋势、背景结构和下一镜首个可读画面。 |
| 声音桥 | 确认声音提前或延后承接的关系，同时保证画面自身的关键因果线索完整。 |
| 长镜头内部段落 | 标清每一阶段的观看落点、注意力转交原因、读取时间和隐藏接缝端点。 |

### 记录有效出口

切点接续以「实际有效末帧」为准，写清人物姿态、支撑脚、持物、地标位置、光照状态、机位高度、朝向、景别、焦点、运动方向与速度趋势以及未完成动作。判断运动余势时，同时查看尾部连续几帧画面或求值曲线，避免单凭一张静帧猜测速度。遇到穿墙、门位错位或角色重复转身的错误末帧时，先修回正确状态再往下接镜。

同一世界速度在不同景别和焦距下的屏幕像速自然不同；下一镜可以带着余势直接跟拍，也可以按节奏切为固定机位。注意力需要从画面左下角手部跳到右上角目标时，预留足够读取时间或用视线、动作引导。

## 三、速度、焦点与快门算式

判断运镜顺不顺，把曲线形状、真实像速、景深清晰区和显示采样分开看：

1. **区分四种速度**：机位线速度、旋转角速度、人机相对速度和屏幕像速。恒定世界速度在近景会产生更大的屏幕位移；相同角速度在长焦窄视场下穿屏更快。完整起停、带速入画切出、刺激后延迟启动各有适用场景，按镜头情绪选用曲线形态。
2. **用真实秒数换算焦点或运镜节奏**：记场景实际帧率 `F = fps / fps_base`，原起点 `s0`、新起点 `s1`、到达帧 `a`：
   - 原持续秒数 `T0 = (a - s0) / F`，新持续秒数 `T1 = (a - s1) / F`。
   - 起点偏移 `Δt = (s1 - s0) / F`（正值更晚启动，负值更早启动）。
   - 持续时间比 `r = T1 / T0`。注意 `r` 反映的是总时长缩放比例，瞬时速度与清晰度仍需结合曲线斜率和画面复看。
3. **分清跟焦、拉焦与镜头呼吸**：持续跟住同一主体靠跟焦，把清晰重点转交给另一深度靠拉焦。两人需要同时看清时直接放大景深范围。调焦时画角发生轻微缩放的现象叫镜头呼吸（lens breathing），与脱焦区分开处理。
4. **区分三类运动成像现象**：

| 现象 | 核心成因 | 对症处理方向 |
|---|---|---|
| 跳格顿挫（Judder） | 帧率采样、单帧屏幕位移过大、快门观感、显示刷新或视口掉帧 | 降低单帧像移、匹配合适快门角度、区分视口卡顿与真实成片速度 |
| 单帧运动拖糊 | 曝光时间内主体或相机相对位移过大，或后期模糊过强 | 调整快门角或运动速度，兼顾单帧清晰度与连续流畅感 |
| 竖线倾斜（果冻） | 实拍逐行扫描时序差，或虚拟渲染中的变形与震动 | 在三维场景里先查相机抖动、网格变形和渲染设置 |

- **理想曝光时长公式**：`t = 快门角 / 360 / fps`。例如 24fps 配 180° 快门角约为 1/48 秒，25fps 配 180° 约为 1/50 秒。
- **横摇速度经验起点**：在 24fps、180° 快门角扫描静态高对比竖线场景时，约 7 秒横摇一幅画宽是常用起步参考；甩镜、跟拍移动主体或不同帧率条件按实际连续画面灵活调整。

## 四、遮挡排查与可见表面核对

检查主体是否真的可读时，把观众必须看清的全部元素列成清单：主体轮廓、关键道具或发射端、接触点、特效和动作方向参照。主体完整入框的同时，还要逐帧核对关键部位有没有被自身遮挡或淹没在同色低对比背景里。

使用自动化射线或构图诊断遇到顶点边缘不稳定时，按下面四步提升测量可靠性：

1. **表面内部采样**：在求值网格三角形内部取重心采样点，先对目标自身做最近表面求交，再对全场景求首个命中，比对对象身份和命中距离容差，防止拿目标背面当命中点误判自身遮挡。
2. **保留全部失败样本**：把未命中、越界、命中他物和距离超差统统留在失败分母里，同时检查近远裁切、安全画框和相邻切点路由。
3. **加设已知遮挡对照**：放一个明知被墙挡住的负对照用例，验证检测逻辑能够准确报出阻挡物名称，确认诊断工具本身可靠再采纳候选。
4. **数值门后再看真实画面**：所有采样指标通过后，在同源同帧条件下对照实际画面，核对关键部位辨识度、动作方向、背景分离度和切点衔接。

## 五、三遍审看流程与记录卡

每次提交正式预演前，按三遍顺序走完审看：

1. **第一遍：原速通看全段**。按目标帧率从头播到尾，检查视线落点、核心事件可读性、空间方向和整体节奏。
2. **第二遍：逐帧定位问题窗口**。停在出框、遮挡、穿模、脱焦或顿挫的几帧，判断问题来自相机、演员、光学、切点还是播放掉帧，挑最小相关变量修改。
3. **第三遍：放回前后镜头原速复看**。确认入点、出点、动作余势和前后衔接顺畅。

只看了单帧截图或逐帧停留时，把原速节奏、动态连续性和播放流畅度记在「待验项」里，等连续预演补齐再关单。

```text
源工程与候选：路径 / SHA / 镜头编号；帧段与实际 fps；预览模式与播放速度
核对七项：身份结构 / 当前状态 / 核心事件 / 空间方向 / 摄影执行 / 焦点可读性 / 接镜衔接
分项结论：通过 / 需返修 / 留给下游验证
画面观察：第几帧、哪个对象出现什么现象，附上对照图或预演片段路径
原因判断：已实证原因 / 待排查假设（区分相机、表演、光学、切点、采样）
修改计划：调整变量、保持不变的锁定项与影响范围
复验结果：同条件 A/B 对照 + 问题窗口 + 前后镜复看结论
```

## 六、13 类常见症状首轮排查

| 画面症状 | 首轮先查 | 优先修复方向 |
|---|---|---|
| 人物变大但空间关系没变 | 查位移、焦距、后期裁切和人物走近 | 分清移机与变焦，对照背景深度地标调整位置 |
| 想环绕却像原地摇、想升高却像仰摇 | 查相机世界轨迹、旋转和人物自转 | 明确指定世界起终点、高度轨迹和光轴朝向 |
| 主体边缘出框 | 查最大动作伸展帧、转向帧和遮挡峰值帧 | 留足运动余量并微调路径，覆盖全帧段而非只看首尾 |
| 人物反向或眼线错位 | 查世界路线与相机是否越轴 | 回到平面图恢复同侧布机，或设计可见越轴过渡 |
| 切镜后动作重复启动或重复落地 | 查上一镜实际有效末帧的动作相位 | 挪动切点顺接剩余动作，删去重复准备段 |
| 手持像随机抖动滤镜 | 查刺激源、握持摆动与恢复落点 | 给晃动加上感知因果和稳定恢复，去掉无源高频抖动 |
| 稳定器画面上下颠簸 | 查水平角稳定与垂直步频位移 | 单独平滑相机 Z 轴高度曲线，与旋转轴分开处理 |
| 调焦时取景轻微收缩或频繁脱焦 | 查对焦距离轨迹、遮挡物与焦距变化 | 分清构图变化与清晰区变化，锁定正确焦点目标 |
| 推拉变焦主体大小漂移 | 查主体距离 `Z` 与焦距 `f` 随时间的比值 | 同步校正位置曲线、焦距曲线和焦点跟随 |
| 高光粘在屏幕固定位置 | 查光源是否误绑在相机下、反射角与材质 | 把环境主灯固定在世界坐标系，让高光随视角自然流动 |
| 遮挡切前后状态跳变 | 查遮挡物进出两端的姿态、持物与地标 | 对齐两端支撑脚、道具位置和空间地标 |
| 二维画面绕圈像纸片 | 查图层厚度与是否缺少转面绘制 | 控制允许的观察角度，或补转面原画与三维辅助模型 |
| 画面构图漂亮但事情没看清 | 查核心事件是否被挡或读取时间太短 | 先腾出清晰读取窗口，再保留主运镜节奏 |
