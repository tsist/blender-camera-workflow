# 运动几何与术语速查

选运镜方法前，先把位置、朝向、视场、焦点和主体运动五个变量拆开，避免只靠行业简称猜操作。本页整理六大控制维度、34 项常用运镜方法、理想透视核算公式，以及 47 项中英术语速查表。

## 一、六大独立控制维度

| 维度 | 观察重点 | Blender 对应关系 |
|---|---|---|
| 位置 | 接近、远离、横移、升降、弧线，观察点本身在移动 | Camera Object 求值后的世界坐标，受父级、约束与 Action 影响 |
| 朝向 | 横摇、俯仰、滚转；升高机位与仰摇镜头是两回事 | 求值后的光轴朝向与上方向，直接读世界朝向避免靠单个欧拉角猜测 |
| 视场 | 焦距、传感器尺寸、适应方式与画幅共同决定视野宽窄 | Camera Data 的 `lens`、`sensor_width`、`sensor_fit`、分辨率与像素比；正交相机看 `ortho_scale` |
| 清晰区 | 持续跟住同一主体，或把焦点转交给另一深度物体 | 景深开关、焦点对象或对焦距离、光圈值，最终以实际渲染画面核对 |
| 主体运动 | 演员走近、转身或转台旋转也会让画面构图变化 | 角色与道具动画曲线，保持与相机调整各自独立 |
| 支撑与后期 | 稳定器/摇臂带来的路径特征，或成片后的二次裁切缩放 | 绑定骨架、约束或合成裁切层，按实际需求单独规划 |

### 容易混淆的三个几何常识

- **横摇与横移的区别**：纯横摇绕投影中心转向，远近物体相对遮挡关系基本不变；横移改变了观察点，近景与远景会产生明显深度视差。远景平坦场景本身视差很弱，判断到底有没有移机要看真实世界路径和深度地标。
- **前导退行的地图方向**：前导跟拍时相机面朝演员向后退，但在场景平面图上，相机和演员沿着同一条前进方向移动。
- **等速与恒尺度的条件**：要让人物在画面里大小稳定，除了相机与人物速度匹配，还要同时核对人机距离、路径曲率、焦距和朝向。稳位置、稳大小、稳地平线、稳注意力是四个独立目标。

## 二、基础操作（A00–A10）

| 编号与方法 | 必须定清的变量 | 判别与实操提醒 |
|---|---|---|
| A00 固定（Locked off） | 机位与朝向锁死；焦距和焦点是否固定单独注明 | 画内人物可以自由运动，固定机位同样适合强表演 |
| A01 横摇（Pan） | 机位不动，写清起止目标与触发时机 | 单看背景横滑容易误判为横移，核对投影中心是否移动 |
| A02 俯仰（Tilt） | 保持机位高度，只改垂直指向 | 需要越过前景遮挡物时改用升降机位，而非原地仰摇 |
| A03 滚转（Roll） | 绕光轴旋转，地平线发生倾斜过程 | 倾斜构图（Dutch angle）是静止状态，滚转是动态过程 |
| A04 推近（Dolly in / Push in） | 真实缩短相机与目标的空间距离 | 核对人物是否同步走近，看前景遮挡与深度比例变化 |
| A05 拉远（Dolly out / Pull back） | 增大相机与目标距离，写明新增的环境关系 | 落幅按叙事需要收住，无需每次都拉成大全景 |
| A06 横移（Truck / Crab） | 相机侧向位移，注明是否配合跟摇 | 朝向锁死时主体会横向移出画框，持续锁定主体需配合横摇 |
| A07 垂直升降（Pedestal / Boom） | 高度轨迹与光轴朝向分开写 | 固定臂长摇臂末端走的是弧线，需要严格垂直运动时走直轨路径 |
| A08 光学变焦（Zoom） | 焦距或视场随时间变化，注明机位是否锁死 | 原位放大只改取景宽窄，透视关系保持不变 |
| A09 拉焦与跟焦（Rack focus / Focus pull） | 起始对象、触发帧、目标深度或持续跟随对象 | 拉焦（rack）做注意力转交，跟焦（focus pull）持续保持同一主体清晰 |
| A10 数字再取景（Digital reframe） | 对已有画面做裁切、平移或缩放 | 只重组已有像素，需要露出被遮挡侧面时回到三维移动机位 |

## 三、跟随与复合方法（B01–B16）

| 编号与方法 | 路径与关系必须写明 | 验收重点 |
|---|---|---|
| B01 前导（Lead shot） | 位于前方或侧前，退行路径与距离趋势 | 脸部与目的地线索可读，人物步伐自然 |
| B02 尾随（Follow shot） | 位于后方或侧后，目标地标与人物让位 | 目的地方向线索露出在人物轮廓外 |
| B03 平行侧跟（Parallel tracking） | 人机两条路线、速度、侧距与曲率 | 肢体最大伸展帧完整入框、前方留白与脚底贴地 |
| B04 斜向跟随与超越（Diagonal / Overtake） | 从侧后移至侧前，写明谁加速与收束方向 | 平面图方向顺畅过渡，主体可见面逐步展开 |
| B05 有限弧移（Arc shot） | 起止方位、旋转中心、半径高度与朝向目标 | 区分相机弧移与人物自转，核对背景地标同步转动 |
| B06 环绕（Orbit） | 绕行角度、半径与高度，按需选半圈或整圈 | 整圈环绕会暴露 360° 场景与灯光，提前备齐四周布景与灯位 |
| B07 揭示与遮蔽（Reveal / Conceal） | 起初被什么挡住、何时解除遮挡 | 属于观看功能，可用横移、升降、推拉或人物走位实现 |
| B08 注意力转交（Relay / Handoff） | 从甲的因果线索过渡到乙、道具或目的地 | 交接瞬间的接触、物件归属与读取窗口完整可见 |
| B09 甩镜（Whip pan / Whip tilt） | 快速转向的触发帧与落幅构图 | 运动模糊受像速与曝光影响，用作剪辑转场时单独核对前后切点 |
| B10 快速变焦（Snap zoom / Crash zoom） | 视场骤变幅度与机位状态 | 明确焦距突变节奏，与高速移机区分开 |
| B11 推拉变焦（Dolly zoom） | 距离与焦距反向协同，以及主体与背景尺度趋势 | 联合核对连续透视、主体近似等大、背景缩放与焦点跟随 |
| B12 升降揭示（Crane reveal） | 升高/降低、平移和俯仰各自的分工 | 升机与拉远、降机与推近按画面需要自由组合 |
| B13 穿行与越过（Push through / Pass by） | 实际通道宽度、避让物体、终点与观察对象 | 核对墙厚、门框与近裁切；若使用虚拟穿墙则在设计卡里明示 |
| B14 反应式手持（Reactive handheld） | 感知刺激 → 身体握持响应 → 视点摆动 → 恢复稳定 | 晃动带因果与恢复目标，替代无源高频抖动 |
| B15 螺旋与复合绕行（Helical move） | 绕行同时叠加高度或半径变化，保留方向参照 | 保持地平线或明确参照物，避免观众彻底迷失方向 |
| B16 停机留人 / 越人留景（Hold and Let go） | 写明谁停下、谁继续、脱离跟随的准确帧 | 留下的画面保留明确的观看信息与情绪余韵 |

## 四、特殊视点与生产方法（C01–C07）

| 编号与方法 | 设计判别要点 | 使用提醒 |
|---|---|---|
| C01 俯视移动（Overhead traverse） | 俯视角度与水平移动路径各自指定 | 正上方静止同样有效，优先保护人物轮廓与接触辨识 |
| C02 身体绑定（Body mounted / Snorricam） | 写明绑定在躯干还是装备、相对姿态与残余起伏 | 躯干绑定仍能看见头部独立转动，与严格双眼视点区分开 |
| C03 车载与独立追车（Vehicle / Tracking vehicle） | 区分固定在被摄车身还是独立跟拍车 | 底座、支臂、云台与镜头视角分层设计 |
| C04 航拍与索道（Aerial / Cable camera） | 平台飞行/索道轨迹与云台指向分开控制 | 按真实可通行区域与障碍边界布线 |
| C05 可重复动控（Motion control） | 路径、焦距、焦点、灯光与触发同步记录 | 多遍合成时同步核对角色与灯光状态一致 |
| C06 连续长镜头（Oner / Long take） | 拆清内部段落、每次注意力转交点与隐藏接缝 | 重点在时间结构与内部节奏，可用支撑交接或隐藏切实现连续观感 |
| C07 特殊光学与虚拟（Probe / Periscope / Virtual） | 明确光学观察点、机身位置与超现实边界 | 写清实拍逻辑还是明确虚拟路径，避免同一镜内自相矛盾 |

## 五、理想透视与投影核算

以下公式用于理想针孔透视下的方向与比例估算（正交相机直接用 `ortho_scale` 核算）：

- **成像投影高度**：`h = f × H / Z`。`f` 为焦距，`h` 为像面高度（同单位）；`H` 为主体高度，`Z` 为投影中心到主体的光轴深度（同单位）。
- **近远比例核算示例**：两个等高物体分别位于 4m 和 8m，投影高度比为 `2 : 1`。原地把焦距翻倍后，两物体投影高度同乘 2，比例依然是 `2 : 1`。沿光轴向前移机 2m，两物体深度变为 2m 和 6m，投影比例变为 `3 : 1`。由此可见，**改变远近透视比例靠移机改距离，改变取景宽窄靠调焦距**。
- **推拉变焦核算示例**：主体高 `H = 1m`，背景同高且始终在主体后方 6m。当主体深度依次为 2m、4m、6m，焦距同步设为 25mm、50mm、75mm 时，主体成像高度始终保持 `12.5mm`；而背景深度依次为 8m、10m、12m，背景成像高度依次变为 `3.125mm`、`5.0mm`、`6.25mm`。后拉增焦让背景相对主体显著变大，推近减焦则让背景相对缩小。
- **画幅与传感器核对**：同一支 50mm 镜头在不同传感器宽度、画幅比例和 `sensor_fit` 下视角不同，比较候选时以实际相机投影结果为准。
